# Tayti Gelateria

Site institucional da Tayti Gelateria, construído com Next.js e preparado para
deploy na Vercel.

## Prerequisites

- Node.js `22.x`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the production Next.js build
- `npm start`: serve the production build locally

## Deploy

The GitHub repository is connected to Vercel. A push to `main` starts a new
production deployment.
